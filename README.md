# Technical Writing Lab

## Overview

This repository contains my work for the **Technical Writing Lab**. The lab provides practical experience in writing different types of technical documentation for different audiences and purposes.

The exercises focus on clear communication, organization, accuracy, audience awareness, and professional documentation practices.

## Learning Objectives

Through these exercises, I practiced how to:

* Write clear and easy-to-follow technical procedures.
* Create structured API reference documentation.
* Summarize technical information for an intended audience.
* Provide constructive and professional peer feedback.
* Explain technical information using simple and appropriate language.
* Organize documentation in a clear and professional format.

## Exercises

### Exercise A – User Manual Procedure

**File:** `Exercise_A_User_Manual.md`

This exercise provides a step-by-step procedure for creating and activating a Python virtual environment and installing a package.

The procedure includes:

* Prerequisites
* Step-by-step instructions
* Expected results for each step
* Screenshot description
* Troubleshooting guidance
* A conclusion explaining the purpose of virtual environments

The procedure is written for a first-semester computing student with basic computer knowledge but no previous experience with Python virtual environments.

### Exercise B – API Reference

**File:** `Exercise_B_API_Reference.md`

This exercise documents a hypothetical API endpoint used to create a new task in a project management application.

The documentation includes:

* HTTP method and endpoint
* Path parameters
* Request headers
* Request body parameters
* Data types and required fields
* Example JSON request
* HTTP response codes
* Example successful JSON response
* Explanation of response fields

The API reference is designed to help developers understand how to use the endpoint correctly.

### Exercise C – Executive Summary

**File:** `Exercise_C_Executive_Summary.md`

This exercise provides an executive summary of the technical writing activities completed in the lab.

It summarizes:

* The purpose of the lab
* The user manual procedure
* The API reference
* The importance of audience and purpose
* The importance of clarity and concision
* The main skills developed through the exercises

The summary demonstrates the ability to communicate technical information to readers who may need a concise overview rather than detailed instructions.
